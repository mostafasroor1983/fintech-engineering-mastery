# المسرد

تعريفات بلغة بسيطة للمصطلحات المستخدمة في الدروس، والمشاريع الختامية، ودليل المقابلات. ورُتبت أبجديًا حسب المصطلح الإنجليزي (كما يظهر في الكود والتوثيق). وحيث يشرح درسٌ المصطلح كما ينبغي، يُذكر بين قوسين معقوفين.

| المصطلح | المعنى |
|---|---|
| **2PC (two-phase commit) – التأكيد على مرحلتين** | بروتوكول يطلب فيه منسق من كل مشارك أن يستعد، ثم يأمر الجميع بالتأكيد أو الجميع بالإلغاء. ذري، لكنه يحجب إن فشل المنسق. [المسار 05 الدرس 15] |
| **ACID** | الذرية، والاتساق، والعزل، والمتانة: ضمانات معاملة قاعدة البيانات. [المسار 08 الدرس 01] |
| **acks=all** | إعداد منتج Kafka: لا يؤكد القائد الكتابة إلا بعد أن تمتلكها كل النسخ المتزامنة. |
| **Actuator** | وحدة في Spring Boot تكشف نقاطًا تشغيلية مثل `/actuator/health`، و`/mappings`، و`/beans`، و`/conditions`. واكشف الصحة والمقاييس فقط علنيًا. [المسار 16 الدرس 01] |
| **ADR (architecture decision record) – سجل القرار المعماري** | وثيقة قصيرة تسجّل قرارًا واحدًا، وسياقه، والخيارات، والعواقب. |
| **Advisory lock – القفل الاستشاري** | قفل في PostgreSQL على رقم يختاره التطبيق (مثل `pg_advisory_xact_lock`) بدل صف؛ ويُستخدم لتسلسل العمل لكل مفتاح. |
| **API versioning (built-in) – إصدار الواجهات المدمج** | ميزة في Spring Framework 7 توجّه الطلبات حسب إصدار مأخوذ من جزء المسار، أو ترويسة، أو معامل استعلام، أو نوع الوسائط (`spring.mvc.apiversion.*`). |
| **At-least-once delivery – التسليم مرة واحدة على الأقل** | كل رسالة تُسلَّم مرة أو أكثر؛ والتكرارات ممكنة، فيجب أن يكون المستهلكون عديمي الأثر عند التكرار. |
| **Authorisation (card) – تفويض البطاقة** | يوافق المُصدِر على دفعة البطاقة ويحجز الأموال؛ وتتحرك الأموال لاحقًا عند التحصيل. [المسار 04 الدرس 18] |
| **BOLA (broken object level authorisation) – كسر التفويض على مستوى الكائن** | المخاطرة رقم 1 في OWASP API Security: تعيد الواجهة كائنًا (مثل دفعة) أو تغيّره دون التحقق من أن المستدعي يملكه. |
| **Break (reconciliation) – الكسر في المطابقة** | فرق بين سجلين للأموال نفسها (مثل دفتر الأستاذ مقابل كشف البنك) يجب على شخص ما تفسيره وحسمه. |
| **Bulkhead – الحاجز** | تحديد عدد الاستدعاءات المتزامنة التي تذهب إلى تبعية واحدة، فلا تستهلك كل السعة. وفي Spring Framework 7: ‏`@ConcurrencyLimit`. [المسار 06 الدرس 03] |
| **camt.053** | رسالة كشف حساب من البنك إلى العميل وفق ISO 20022: كشف الحساب في نهاية اليوم الذي يرسله البنك. |
| **Capture (clearing) – التحصيل (المقاصة)** | يطلب التاجر أموال دفعة بطاقة مفوّضة، كليًا أو جزئيًا. |
| **Chargeback – رد المبلغ** | يعترض حامل البطاقة على دفعة عبر مُصدِره؛ وتعكس الشبكة الأموال من جانب التاجر بانتظار الأدلة. |
| **Circuit breaker – قاطع الدائرة** | يتوقف عن استدعاء تبعية تستمر في الفشل لفترة، ثم يحاول مجددًا بحذر. [المسار 06 الدرس 02] |
| **Compensation – التعويض** | إجراء أعمال جديد يلغي أثر خطوة سابقة في ساغا (مثل الاسترداد)، لا تراجعًا في قاعدة البيانات. [المسار 05 الدرس 23] |
| **Constant-time comparison – المقارنة بزمن ثابت** | مقارنة الأسرار بحيث لا يكشف الوقت المستغرق عدد البايتات الأولى المتطابقة (`MessageDigest.isEqual`). |
| **CQRS** | فصل مسؤولية الأوامر والاستعلامات: نماذج منفصلة لكتابة البيانات وقراءتها. [المسار 05 الدرس 19] |
| **Dead-letter topic (DLT) – موضوع الرسائل الميتة** | حيث تذهب الرسالة بعد فشل إعادات المحاولة المحدودة، فلا تحجب القسم؛ ويجب مراقبته. [المسار 09 الدرس 11] |
| **Deferred constraint trigger – مشغّل القيد المؤجل** | مشغّل في PostgreSQL يُفحص عند COMMIT بدل بعد كل عبارة؛ ويُستخدم للتحقق من توازن مُدخل اليومية. |
| **Double-entry bookkeeping – القيد المزدوج** | تُسجَّل كل حركة أموال كقيود مجموعها صفر (لكل عملة). [المسار 05 الدرس 01] |
| **Dual write – الكتابة المزدوجة** | الكتابة في نظامين (مثل قاعدة البيانات وKafka) دون معاملة مشتركة واحدة؛ والتعطل بينهما يتركهما غير متسقين. [المسار 05 الدرس 07] |
| **End-to-end id – المعرّف من طرف إلى طرف** | مرجع يضعه الدافع ويرافق الدفعة عبر كل بنك؛ ويُستخدم لمطابقة أسطر البنك مع عناصر دفتر الأستاذ. و`NOTPROVIDED` تعني عدم وجوده. |
| **Expand/contract migration – ترحيل التوسيع/التقليص** | تغيير المخطط بخطوات متوافقة مع الإصدارات السابقة (إضافة، وكتابة مزدوجة، وملء، وتحويل، وإزالة) فيعمل الكود القديم والجديد معًا. [المسار 16 الدرس 02] |
| **Fencing token – رمز التسييج** | رقم يزداد مع كل منح للقفل؛ ويرفض المورد المحمي الكتابات برمز أقدم، فلا يستطيع عميل متوقف الكتابة بعد فقدان القفل. |
| **Full jitter – التشتيت الكامل** | تأخير إعادة المحاولة يُختار عشوائيًا بين 0 وسقف التراجع الأسي، فلا يعيد عملاء كثيرون المحاولة في اللحظة نفسها. [المسار 06 الدرس 04] |
| **HMAC** | تجزئة بمفتاح (هنا HMAC-SHA256) تُستخدم لتوقيع حمولات webhooks فيتحقق المستقبِلون من المرسل والسلامة. |
| **HTTP Service Client – عميل خدمة HTTP** | واجهة Java موسومة بـ `@HttpExchange`/`@PostExchange` يولّد لها Spring عميل HTTP؛ وتُسجَّل بـ `@ImportHttpServices`. |
| **Idempotency key – مفتاح عدم التكرار** | قيمة فريدة يختارها العميل وتُرسل مع الطلب (الترويسة `Idempotency-Key`) فيتعرف الخادم على إعادات المحاولة ويعيد النتيجة الأصلية. [المسار 05 الدرس 12] |
| **Idempotent consumer – المستهلك عديم الأثر عند التكرار** | مستهلك رسائل يسجّل معرّفات الرسائل المعالجة في المعاملة نفسها مع أثرها، فلا تغيّر التكرارات شيئًا. [المسار 05 الدرس 08] |
| **ISO 20022** | معيار المراسلة المالية الدولي (مثل pacs.008 لتحويل الائتمان، وcamt.053 للكشف). [المسار 04 الدرس 07] |
| **Jackson 3** | مكتبة JSON التي يستخدمها Spring Boot 4 ‏(الحزمة `tools.jackson`)؛ وافتراضياتها تختلف عن Jackson 2 ‏(مثل ترتيب الخصائص، والتشدد في null للأنواع البدائية). |
| **Journal entry / posting – مُدخل اليومية / القيد** | مُدخل اليومية حدث أعمال واحد في دفتر الأستاذ؛ والقيود أسطره، كل منها يخصم من حساب واحد أو يضيف إليه. |
| **Lease (work claim) – عقد الإيجار (المطالبة بالعمل)** | تعليم صف بأنه مأخوذ حتى وقت معين (`lease_until`) فيتخطاه العمال الآخرون؛ وإن مات العامل، ينتهي العقد ويعيد عامل آخر المحاولة. |
| **Maker-checker (four-eyes) – الصانع والمدقق (مبدأ الأعين الأربع)** | ضابط يُجري فيه شخص تغييرًا ويوافق عليه شخص مختلف. |
| **Minor units – الوحدات الصغرى** | الأموال مخزنة كعدد صحيح من أصغر وحدة للعملة (البنس، والسنت): ‏10.50 GBP = 1050. |
| **MVCC** | التحكم في التزامن متعدد النسخ: يرى القراء لقطة بينما ينشئ الكتّاب نسخًا جديدة من الصفوف. [المسار 08 الدرس 03] |
| **Optimistic locking – القفل المتفائل** | اكتشاف التحديثات المتعارضة بعمود إصدار (`@Version`)؛ فتفشل المعاملة الخاسرة وتعيد المحاولة. [المسار 05 الدرس 16] |
| **Outbox (transactional) – صندوق الصادر (المعاملاتي)** | كتابة صف الحدث في معاملة قاعدة البيانات نفسها مع تغيير الأعمال، ثم نشره إلى الوسيط بشكل منفصل. [المسار 05 الدرس 13] |
| **PAN / token – رقم البطاقة / الرمز** | ‏PAN هو رقم البطاقة؛ والرمز قيمة بديلة عديمة الفائدة إن سُرقت. وتخزين الرموز فقط يقلل نطاق PCI DSS. |
| **Pessimistic locking – القفل المتشائم** | قفل الصفوف قبل تغييرها (`SELECT … FOR UPDATE`) فتنتظر المعاملات الأخرى. [المسار 05 الدرس 17] |
| **Pinning (virtual threads) – التثبيت (الخيوط الافتراضية)** | خيط افتراضي ملتصق بخيط نظام التشغيل الحامل له أثناء الحجب (على JDK 21–23: داخل `synchronized`)؛ وأُصلح لـ `synchronized` في JDK 24 ‏(JEP 491). |
| **ProblemDetail (RFC 9457)** | صيغة أخطاء JSON قياسية (`application/problem+json`) بالحقول `type`، و`title`، و`status`، و`detail`. |
| **Reconciliation – المطابقة** | مقارنة سجلين مستقلين للأموال نفسها وتفسير كل فرق. [المسار 05 الدرس 22، والمسار 04 الدرس 12] |
| **RESHADED** | خطة مقابلة التصميم: المتطلبات، والتقدير، والمخطط، والتصميم عالي المستوى، والواجهة، والتعمق، والتقييم، والتسليم. [المسار 15 الدرس 02] |
| **Saga – الساغا** | تسلسل من المعاملات المحلية مع تعويضات، يُستخدم بدل معاملة موزعة واحدة. [المسار 05 الدرس 14] |
| **SKIP LOCKED** | ‏`SELECT … FOR UPDATE SKIP LOCKED`: خذ الصفوف التي لم يقفلها أحد، وتخطَّ البقية؛ ويُستخدم لطوابير العمل. |
| **SLI / SLO – مؤشر وهدف مستوى الخدمة** | مؤشر مستوى الخدمة (قيمة مقاسة، مثل زمن الاستجابة p99) وهدفه (القيمة المستهدفة، مثل p99 < 300 مللي ثانية في 99.9% من الدقائق). [المسار 06 الدرس 01] |
| **SSRF** | تزوير الطلبات من جانب الخادم: خداع الخادم لاستدعاء عنوان يختاره المهاجم، مثل خدمة داخلية أو بيانات وصفية سحابية. ‏OWASP API7. |
| **Stand-in decision – القرار البديل** | قرار احتياطي متفق عليه مسبقًا حين لا تستطيع تبعية (هنا محرك الاحتيال) الإجابة في الوقت المناسب. |
| **STAR** | الموقف، والمهمة، والإجراء، والنتيجة: هيكل لإجابات المقابلات السلوكية. [المسار 15 الدرس 01] |
| **Token bucket – دلو الرموز** | تحديد معدل تُعاد فيه تعبئة الرموز بمعدل ثابت حتى سعة معينة، ويأخذ كل طلب رمزًا واحدًا. [المسار 02 الدرس 17] |
| **Virtual threads – الخيوط الافتراضية** | خيوط JVM خفيفة (نهائية في Java 21) تجعل الإدخال/الإخراج الحاجب رخيصًا؛ وتضيف تزامنًا، لا سرعة. [المسار 03 الدرس 12] |
| **XXE** | هجوم الكيانات الخارجية في XML: مستند XML خبيث يجعل المحلل يقرأ ملفات محلية أو عناوين. وعطّل DTD والكيانات الخارجية. |
